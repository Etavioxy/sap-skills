# docs/concrete-insight.md 格式规范

`docs/concrete-insight.md` 用**真实数据 + 图**演示核心概念链路（SAP spec1 > concrete-insight 阶段产物）。

定位：每个核心概念的链路用真实数据 / 图具体化，回答「这条链路长什么样」，不写空洞抽象。可以是实测，也可以是设计推演——有具体支撑即可。
职责边界：concrete-insight 是「具体链路演示」；docs 是「概念怎么实现」；concrete-insight 的真实值可作为 spec 验收的目标值。

## 内容组织

每个主题一个 `##` 节（每个主题演示一条链路）。要点：

- **真实数据**——表格或代码块展示实际值（来源位置 / 内容形态 / 关键字段）。
- **图 / 时序**——ASCII 图或时序块演示链路如何流动。
- 数据必须可溯源（文件:行号 / 真实命令输出），不编造数字。
