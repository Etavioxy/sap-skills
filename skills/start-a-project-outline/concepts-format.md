# concepts.md 格式规范

`concepts.md` 是领域概念的**唯一术语源**（SAP concepts 阶段产物）。

职责边界：`concepts.md` 回答「是什么、边界在哪」；`docs/` 回答「怎么实现、接口长什么样」。

## 概念条目格式

每个概念一个条目，包含：

- **标题**——中英文术语并列：英文 + 中文，如 `Concept（概念）`。
- **编号**——`1.` / `1a.`（子概念）等，供 ideas / spec / docs / 各文档引用，不重复定义。
- **定位**——概念是什么，一句话讲清。
- **边界与关系**——在正文中直接陈述：与相关概念的界限、被谁使用、在整体中的位置。不用独立小节，揉进概念描述。

实现细节、协议、config 字段、命令集归对应 `docs/`，不在概念条目里展开。

## 例子

每个例子用一段叙述分析一条完整过程，概念标注揉进叙述（加粗概念名），例子中不用表格。用覆盖矩阵核验每个概念都被覆盖。

## 覆盖矩阵

`concepts.md` 含概念间关系覆盖矩阵（SAP 定义）。常见形式是**概念 × 例子矩阵表**：

```
| 概念 \ 例 | 例 A | 例 B | 例 C |
|------|:---:|:---:|:---:|
| C1 ... | ✅ |   | ✅ |
```

约束：每个概念至少被一例覆盖；一例至少覆盖三个概念；例数与概念数不对等。
