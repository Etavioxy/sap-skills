# spec — 演进流程

本 skill 是动态开放的：内容随实践持续补充。

- 新思想先进 drafts/（自由文本，一句或一段，附来源），不直接改 SKILL.md。
- 验证（用户确认或代码实证）后提升进 SKILL.md 的对应位置（评估手段 / 评估三问 / Consistency / Blast Radius 度量 / 权衡模板）。
- 模板不追求一行，写清楚判断即可。
- SKILL.md 不含任何"开放/演进"元话，只留调用 agent 用的内容；演进机制与草稿都在 Notes 侧。
- 结构原则：整体骨架错落有致、详略得当——Consistency 与 Blast Radius 是教程节（展开），权衡模板是一段判断（收紧），评估手段/三问是引导。
- 层级原则：评估手段（怎么评估：按层逐个深入，把足迹想全）与评估三问（评估什么）分离；跨层差异属于 Blast Radius 的度量维度，不属于 Consistency（一致性管同层内同构，层级差异管跨层不同构）。
