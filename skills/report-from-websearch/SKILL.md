# Report from Websearch

原子职责：**给定 web 调研素材，产出一份符合约定的 markdown 报告**。只做「产出」，不负责调研。

调研在进入本 skill 前完成：
- 需要先做 web 调研 → 请 invoke [[mattpocock-skills:research]]

## 报告命名

`reports/<topic>.md`，`<topic>` 为小写连字符分隔的主题，不带日期。

## 证据分级

全文每条结论必须绑定一个级别：

| 级别 | 含义 |
|---|---|
| 【文档明确】 | 官方文档 / 规格写明 |
| 【源码推断】 | 从源码直接读出 |
| 【实测】 | 本地运行 / 实验验证 |
| 【未查到官方说明】 | 官方渠道查不到，不做猜测 |

## 基本标题格式

```
# <主题>报告
日期 / 范围 / 依据          ← 三行元信息
执行摘要                    ← 编号列最有用的结论
逐主题分析                  ← 每条结论绑定证据 + 分级
未确认边界                  ← 明确未覆盖处
## 来源                     ← 末尾来源清单，见「引用方式」
```

## 引用方式

- 正文引用：**短来源名 + 证据分级**，不贴 URL。短名规则：
  - 仓库 / issue / 文档：`visx#819` 这类可读短名
  - 代码：`文件:行号`
  - 实测：`trace:<文件>` 或 `<文件>`
- 末尾「## 来源」：每行一条 `短名：URL`，短名与正文一致，作为正文↔来源的共享键
- 无 URL 的本地证据（源码行号 / 实测文件）也列出，标「本地」
- 引用 issue / 讨论用原始评论（`gh api` 拉取），不信二手摘要
- 每条结论至少绑一个证据
